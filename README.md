# Thief Mechanics

Плагин для **HL2RP** на базе **Helix** и сборки/фреймворка **SchwarzKruppzo (Autonomous)**.

Добавляет механику взлома закрытых ящиков с паролем и дверей, закрытых игроком, при помощи отмычек.

## Совместимость

Скорее всего работает со сборками вроде:

- **Autonomous** (SchwarzKruppzo)
- **Cellar** и форки на той же базе

Требует типичный стек Helix HL2RP с:

- контейнерами (`ix_container` + пароль)
- системой дверей Helix (`doors` / ключи игрока)
- крафтом (`ixcraft` / `recipes_crafting`)

## Возможности

### Предметы

| Предмет | ID | Описание |
|---|---|---|
| Отмычка | `lockpick` | 50% открыть / 25% не открыть / 25% сломаться |
| Отвёртка с заколкой | `lockpick_improvised` | 25% открыть / 50% сломаться / 25% открыть и сломаться |
| Заколка | `bobby_pin` | Компонент для крафта импровизированной отмычки |

### Взлом

- Закрытые **ящики** с паролем (`ix_container`)
- **Двери игроков**, закрытые ключами
- Прогресс-бар + звуки при взломе
- Шанс поломки отмычки

Не взламываются:

- двери с комбайновским замком
- faction / class двери
- незанятые двери без владельца

### Крафт

- **Ремесло 2:** заколка, отвёртка с заколкой
- **Ремесло 3:** обычная отмычка

## Установка

1. Скопируйте папку `thiefmechanics` в `gamemodes/ixhl2rp/plugins/`
2. Включите плагин в меню Helix / конфиге плагинов
3. Перезапустите карту или сервер
